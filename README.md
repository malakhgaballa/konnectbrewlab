# konnectbrewlab
Interactive data science workshop for KONNECT Summit 2026

This is a static, self-contained HTML app.

Quick test: open index.html in Chrome or Safari.

GitHub Pages: create a public repository, upload index.html to its root, go to Settings > Pages, choose Deploy from a branch, main, /(root), Save. Wait for the Pages URL and open it on a phone.

Netlify Drop: visit https://app.netlify.com/drop and drag the unzipped folder onto the upload area.

No backend, accounts, or database required. All synthetic case data is embedded. The file is large; first load may take time on older phones.

Important: integration preserves existing forecasting and scenario UI logic; full cross-screen financial QA and device testing still needed.
